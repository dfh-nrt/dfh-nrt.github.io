## Docker

Docker adalah container runtime engine dan container adalah proses terisolasi yang ringan (lightweight) yang berjalan di level kernel OS, bahasa yang mudah untuk container adalah virtualisasi di level kernel OS. Jika sebelumnya virtualisasi dilakukan di level OS dengan virtual machine, container ini lebih praktis karena hanya akan menginstall package atau yang diperlukan saja saat berjalan.

Dengan konsep tersebut, salah satu keuntungan container adalah tidak terpaku dengan OS dimana aplikasi dibuat sehingga mengurangi permasalahan it works on my machine but not on production. 

Jika produk vmware, proxmox, dan virtual box adalah hypervisor dalam virtualisasi OS maka docker serupa dalam teknologi containerisasi.
