## Proxmox

#### Proxmox

Proxmox VE (Virtual Environment) adalah platform manajemen virtualisasi open source yang memungkinkan user untuk me-manage VM, container dan storage via web interface maupun CLI. 

Proxmox VE berbasis KVM (Kernel-based Virtual Machine) dan LXC (Linux Containers) teknologi virtualisasi dan support berbagai Operating System seperti linux, windows dan macOS. Proxmox menyediakan manajemen berbasis web yang tercentral yang memungkinkan user untuk membuat, mengkonfig dan manage VM dan container juga storage dan network.

Selain via web proxmox juga dapat digunakan via CLI (Command Line Interface) atau shell yang dapat diakses melalui SSH atau di interface webnya pun ada.
